Como jogar / controles
  • Clique em um jogo: ele abre aqui mesmo, com o player do Internet Archive.
  • Clique dentro da tela do jogo para o teclado funcionar. Esc fecha e volta ao acervo.
  • Arcade: setas para mover, Ctrl/Alt para os botões e Espaço para inserir ficha (coin).
  • Consoles (Atari 2600/7800, Mega Drive, Super Nintendo, ColecoVision…): setas + Z/X (e A/S para os outros botões); Enter costuma ser Start.
  • MS-DOS: mouse e teclado. Clique na tela para capturar o mouse; use o menu do player para tela cheia.
  • Use o botão de tela cheia do próprio player para jogar em tela grande.
  • Nintendo DS: use a aba Nintendo DS e escolha o seu arquivo .nds — o jogo roda no seu navegador, sem upload.
  • Meus jogos: na aba Meus jogos você roda arquivos seus de PlayStation 1, Nintendo 64, NES, SNES, Game Boy/GBA, Mega Drive e outros — também sem upload. Catálogos comerciais de PlayStation, Xbox e Nintendo não podem ser incluídos por direitos autorais; no Xbox, use o console ou o serviço oficial.
  • Sala online: na aba Sala online o anfitrião abre o jogo do próprio arquivo, recebe um código de 6 caracteres e os amigos entram com esse código para jogar junto.

Jogando: —

Sala online com código

Jogue junto pela internet sem instalar nada. O anfitrião abre o próprio arquivo do jogo aqui no navegador e recebe um código de 6 caracteres; os amigos entram com o código, veem a tela e controlam pelo teclado — no estilo “Remote Play”. O jogo não é enviado para servidor nenhum: a imagem sai do PC do anfitrião direto para os convidados.

Vale para jogos que rodam no emulador do site (o seu arquivo). Os jogos do acervo abrem dentro do site do Internet Archive e não podem ser ligados em sala.

Entrar na sala (convidado)

Peça o código de 6 caracteres para quem criou a sala.

Clique na tela para o teclado valer. Teclas padrão: setas, Z/X, A/S, Enter, V — use o botão Teclas para trocar. Controle USB/Bluetooth conectado no seu PC também funciona: os botões são enviados ao anfitrião. Se a imagem não aparecer, o anfitrião ainda está carregando.
